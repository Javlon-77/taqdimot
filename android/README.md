# WorldCall Android

Bu papka Taqdimot GitHub Pages saytini Android ilovaga o‘raydi.

Nomi: WorldCall
Package: uz.javlon.taqdimot
Sayt: https://javlon-77.github.io/taqdimot/

Kamera va mikrofon ruxsatlari qo‘shilgan. Android Back tugmasi WebView tarixida ishlaydi.

Android Studio:
1. android papkasini Open qiling.
2. Gradle sync tugashini kuting.
3. Build > Generate Signed Bundle / APK > Android App Bundle.
4. Keystore yarating va xavfsiz saqlang.
5. Release AAB ni Google Play Console ga yuklang.

Keystore va parollarni GitHub ga yuklamang.
